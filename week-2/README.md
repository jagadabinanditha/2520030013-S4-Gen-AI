# Week 2 - Provider-Agnostic LLM Client

## Project Description
This project creates a common interface to interact with different Large Language Model (LLM) providers.

## Supported Providers
- Google Gemini API
- Ollama (Local LLM)

## Technologies Used
- Python
- Google GenAI
- Ollama
- Requests
- Pytest

## How to Run

1. Install dependencies:
   python -m pip install -r requirements.txt

2. Run the application:
   python main.py
